The rules

Rock Paper Scissors is a simple hand game for two players, often used for fun and for making quick decisions. Each choice beats one and loses to another.

🪨 → ✂️
Rock beats Scissors
✂️ → 📄
Scissors beats Paper
📄 → 🪨
Paper beats Rock

If both players choose the same option, the round is a draw.

Ludo rules

Ludo is a race game for 2–4 players. Get all four of your tokens around the board and into the centre first.

Leave the yard

Roll a 6 to bring a token onto the board.

Roll again

A 6, a capture, or a token reaching the centre gives you another turn.

Capture

Land on a rival to send it back to its yard, unless it’s on a start square or a ★ square.

Exact finish

A token needs the exact number to reach the centre.

About the project

This project is a command-line game written in Python. The user types a choice, the computer picks randomly, and the result of each round is shown right away.

Random computer

Python’s built-in random module picks Rock, Paper or Scissors for the computer.

Input validation

The game checks every entry and asks again if the choice isn’t valid.

Multiple rounds

Players can keep playing, and the game tracks the score across rounds.

Simple interface

A plain command-line interface keeps the focus on the game logic.

The core logic

A short example of how the game could work in Python.

import random

choices = ["rock", "paper", "scissors"]
beats = {"rock": "scissors", "scissors": "paper", "paper": "rock"}
user_score = computer_score = 0

while True:
    user = input("Rock, paper or scissors? (q to quit): ").lower()
    if user == "q":
        break
    if user not in choices:
        print("Please enter rock, paper or scissors.")
        continue

    computer = random.choice(choices)
    print(f"Computer chose {computer}.")

    if user == computer:
        print("It's a draw!")
    elif beats[user] == computer:
        print("You win this round!")
        user_score += 1
    else:
        print("Computer wins this round.")
        computer_score += 1

    print(f"Score: You {user_score} – Computer {computer_score}")
